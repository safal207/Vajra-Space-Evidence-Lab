# M87* Reference Case

## Headline claim

> M87* is a supermassive black hole.

This must be decomposed into atomic claims:

1. **OBS** — a compact radio source is observed at the center of M87.
2. **OBS** — calibrated interferometric observables contain horizon-scale structure.
3. **REC** — a ring-like image is reconstructed from calibrated measurements.
4. **INF** — the morphology is consistent with emission around a compact massive object.
5. **INF** — mass and compactness are consistent with a supermassive black-hole model.
6. **PRED** — future observations should preserve declared signatures within uncertainty bounds.
